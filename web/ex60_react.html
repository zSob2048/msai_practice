js파일 有
Node.js를 통해 react 환경설정 다 된 프로젝트 생성...> 설치

Node.js add-on 관리해주는 yarn 설치
npm install yarn -g

vscode의 add-on 확장프로그램
ESLint: JS소스 자동완성용
Prettier - Code formatter : JS소스 정렬
ES7+ React/Redux/... : React 소스 자동완성

프로젝트 만들곳에 가서 cmd
yarn create react-app 프로젝트명
실행 cd 프로젝트명
yarn start > Node.js서버에 올려서 돌려줌 & 자동 재시작 & 브라우저 등...
vanillaJS/JQ : html에서 event 발생시 페이지 전체 새로 렌더링(소스>화면)
React : Virtual DOM 사용(소스>VDOM>화면)
정적인 사이트 > vJS/JQ // 동적인 사이트 > React
개발 끝난 React 프로젝트 > cmd에서 react 종료(Ctrl+C) > yarn build : build라는 폴더 생김 >> build폴더를 서버로
서버에 올려둬야만 index파일이 정상작동
