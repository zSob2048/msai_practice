입력
db.배열명.insertOne( { 필드 : 값 , 필드 : 값 , ...} );


서치
db.배열명.find( { 필드 : 값 });
db.배열명.find( { 필드 : { 연산자 : 값 } });

JS연산자
>  : $gt  (greater than)
>= : $gte (greater than equal)
!= : $ne  (not equal)
<= : $lte (less than equal)
<  : $lt  (less than)

(str) 포함 '%값%' : $regex

and : $and
or  : $or
db.배열명.find( { $and : [js객체, js객체, ...] } );
db.배열명.find( { $or : [ {필드 : { 연산자 : 값 }} , {필드 : { 연산자 : 값 }} ] } );
db.product_1114.find({$and:[{p_price :{$gte:2000}},{p_price :{$lte:4000}}]});

정렬
db.배열명.find(js객체).sort({필드명:1,필드명:-1,...});
(1: 오름차순, -1: 내림차순)
db.product_1114.find().sort({_id:1});

정렬 후 n번째...
db.배열명.find(js객체).sort({필드명:1,필드명:-1,...}).skip(1).limit(3);
( skip(부터).limit(까지) )

수정
db.배열명.updateMany({필드:값을},{$set: {필드:값으로}});
역사> 후자의 js객체로 변환 : {id: A, ans: a} > updateMany{id: A},{ans:b} > {ans:b} 와 같이 객체 자체가 변함... 이었는데 요즘엔 에러

삭제
db.배열명.deleteMany(js객체);
db.배열명.deleteMany(_id:{$regex:"A"}); 등...
